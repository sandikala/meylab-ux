Setup & Panduan

Langkah-langkah menyambungkan platform ke server

Tentang platform ini: Sistem menggunakan Supabase sebagai database — gratis hingga 500MB dan 50.000 baris data. Cukup untuk ratusan kelas selama bertahun-tahun. File HTML di-host di GitHub Pages (gratis selamanya).
1

Buat Akun Supabase

Database gratis untuk menyimpan semua jawaban mahasiswa

Kunjungi supabase.com → klik Start your project → daftar dengan akun GitHub atau email kampus.

  1. Klik New project
  2. Beri nama: meylab-ux
  3. Pilih region: Southeast Asia (Singapore) — paling dekat Indonesia
  4. Klik Create new project — tunggu ~2 menit
2

Buat Tabel Database

Jalankan SQL berikut di Supabase SQL Editor

Di Supabase, klik menu SQL Editor di sidebar kiri, lalu paste dan jalankan SQL berikut:

-- Buat tabel responses CREATE TABLE responses ( id BIGSERIAL PRIMARY KEY, timestamp TIMESTAMPTZ DEFAULT NOW(), nama TEXT NOT NULL, nim TEXT NOT NULL, kelas TEXT, aplikasi TEXT NOT NULL, pengalaman TEXT, sus_score INTEGER, umux_score INTEGER, ueq_attractiveness NUMERIC, ueq_perspicuity NUMERIC, ueq_efficiency NUMERIC, ueq_dependability NUMERIC, ueq_stimulation NUMERIC, ueq_novelty NUMERIC, sus_raw TEXT, ueq_raw TEXT, umux_raw TEXT ); -- Izinkan mahasiswa mengirim data tanpa login (INSERT only) ALTER TABLE responses ENABLE ROW LEVEL SECURITY; CREATE POLICY "allow insert for all" ON responses FOR INSERT WITH CHECK (true); CREATE POLICY "allow select for all" ON responses FOR SELECT USING (true);

Klik tombol Run (▶) — jika berhasil akan muncul pesan "Success".

3

Ambil URL & API Key

Dua nilai yang perlu dipasang di kedua file HTML

Di Supabase, klik Settings (ikon gear) → API. Salin dua nilai ini:

Project URL
https://xxxxxxxxxxxx.supabase.co
anon / public key
eyJhbGci... (kunci panjang)
4

Pasang Key di Kedua File HTML

index.html (mahasiswa) dan dashboard.html (dosen)

Buka kedua file HTML dengan teks editor (Notepad, VS Code, dll). Cari dan ganti dua baris ini:

// SEBELUM (ada di kedua file): const SUPABASE_URL = 'GANTI_DENGAN_URL_SUPABASE_ANDA'; const SUPABASE_KEY = 'GANTI_DENGAN_ANON_KEY_SUPABASE_ANDA'; // SESUDAH (isi dengan nilai dari Supabase): const SUPABASE_URL = 'https://xxxx.supabase.co'; const SUPABASE_KEY = 'eyJhbGciOiJIUzI1Ni...';
Keamanan: anon key aman dipublikasikan — hanya bisa INSERT dan SELECT. Kunci service_role jangan pernah dipasang di file HTML!

Juga ganti password dosen di dashboard.html:

const DOSEN_PASSWORD = 'password_baru_anda';
5

Upload ke GitHub Pages

Host kedua file gratis selamanya

  1. Buat akun di github.com jika belum ada
  2. Klik "+" → New repository
  3. Nama: meylab-ux, pilih Public
  4. Klik Create repository
  5. Upload index.html dan dashboard.html
  6. Ke Settings → Pages → Source: main / root → Save
URL yang akan aktif:
Mahasiswa: https://[username].github.io/meylab-ux/
Dosen: https://[username].github.io/meylab-ux/dashboard.html
✓

Selesai! Bagikan ke Mahasiswa

Platform siap digunakan

Bagikan URL index.html ke mahasiswa via grup WA/LMS. Data akan langsung masuk ke tab Data Mahasiswa di dashboard ini.
